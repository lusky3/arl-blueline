# Code of conduct

This project is a small, volunteer-run effort for a recreational league. We want it to be a pleasant place
to ask questions, report problems and contribute.

## Expected behaviour

- Be respectful and assume good faith. Disagree with ideas, not people.
- Keep discussion on topic and constructive; give specific, actionable feedback.
- Respect people's time and privacy. Do not share anyone's personal information, including league members'.

## Unacceptable behaviour

Harassment, insults, discriminatory language, personal attacks, sustained disruption, and publishing
others' private information are not acceptable.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests, and may restrict participation, when
behaviour breaks these rules. To report a problem, use GitHub's *Report content* on the comment, or contact
the repository owner through their GitHub profile.

This applies in this repository's issues, pull requests and discussions.
