# `blueline` R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `blueline` — a standalone WordPress theme replacing `rookie-child` + `rookie` on rookiehockey.ca — with the full public site, a season-aware homepage, and a league-first My Account that deprecates `yith-woocommerce-customize-myaccount-page`.

**Architecture:** Classic PHP theme (not FSE — SportsPress Pro is not FSE-compatible). Design tokens as CSS custom properties in `style.css`; component CSS built by `@wordpress/scripts` (webpack) from `assets/src/` into `assets/dist/`. Pure decision logic (season state, player-name matching, endpoint maps) lives in small testable functions covered by PHPUnit with stubs; rendering is verified by HTTP smoke tests against staging.

**Tech Stack:** PHP 8.3, WordPress 6.9.6, SportsPress Pro 2.7.26, WooCommerce 11.0.0, `@wordpress/scripts` (webpack), PHPUnit 11, vanilla ES2017+ (no jQuery in new code), self-hosted Barlow Condensed + Inter.

**Design source of truth:** `docs/superpowers/specs/2026-08-11-arl-blueline-theme-design.md`. Read it before starting any task.

## Global Constraints

- Theme slug and text domain: `blueline` everywhere.
- Supports WP 6.9+, PHP 8.1+, SportsPress Pro 2.7+, WooCommerce 11+.
- Never modify WordPress core or plugin files.
- All output escaped: `esc_html()`, `esc_url()`, `esc_attr()`, `wp_kses_post()`. All input sanitized.
- `$wpdb` queries always via `$wpdb->prepare()`. Capability checks before any privileged write.
- WPCS compliance: `phpcs --standard=WordPress`.
- No inline styles emitted from PHP — CSS custom properties or classes only.
- Every SportsPress and WooCommerce touchpoint guarded with `class_exists()` / `function_exists()`. The theme must not fatal if either plugin is deactivated.
- **`get_permalink()` is unreliable on this site** (Page Links To filters it). Use `post_name` + `post_parent` to build real paths.
- **Never use ice blue `#74C0E1` as text on a light background** (1.94:1). It is a fill only.
- Target WCAG 2.2 AA.
- Build artifacts in `assets/dist/` are committed (the deploy copies files directly; there is no build step on the server).
- Commit after every task.

**A note on how this plan specifies work.** Logic that can be wrong in a subtle way — season
state, name matching, endpoint maps, stat normalisation — is given as exact code with a
failing test first. Presentation work (CSS, markup) is specified as **binding requirements**
against the design language in spec §3 rather than literal stylesheets, because the token
vocabulary in Task 2 plus the device rules are the real contract and transcribing a thousand
lines of CSS here would not make the result more correct. Requirements written as "must" are
not optional.

`scripts/smoke-staging.sh` — asserts pages return 200 and contain a marker. Starts with a single case; later tasks add cases.

```bash
#!/usr/bin/env bash
# HTTP smoke tests against staging. Usage: ./scripts/smoke-staging.sh
set -uo pipefail
BASE="${BASE:-https://staging.rookiehockey.ca}"
FAIL=0

check() { # check <path> <expected-http> <grep-marker-or-->
  local path="$1" want="$2" marker="${3:--}" body code
  body="$(curl -sS --max-time 30 -w '\n%{http_code}' "$BASE$path" 2>/dev/null)" || { echo "FAIL $path (curl error)"; FAIL=1; return; }
  code="${body##*$'\n'}"; body="${body%$'\n'*}"
  if [ "$code" != "$want" ]; then echo "FAIL $path -> HTTP $code (want $want)"; FAIL=1; return; fi
  if [ "$marker" != "-" ] && ! grep -qF "$marker" <<<"$body"; then
    echo "FAIL $path -> missing marker: $marker"; FAIL=1; return
  fi
  echo "ok   $path ($code)"
}

check / 200 -

exit $FAIL
```

- [ ] **Step 1: Write the contrast guard test first**

`themes/blueline/tools/check-contrast.mjs` — parses `style.css` and asserts the documented ratios. This is the executable form of spec §3.2.

```js
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, resolve } from 'node:path';

const here = dirname( fileURLToPath( import.meta.url ) );
const css = readFileSync( resolve( here, '../style.css' ), 'utf8' );

const token = ( name ) => {
	const m = css.match( new RegExp( `--${ name }:\\s*(#[0-9a-fA-F]{6})` ) );
	if ( ! m ) throw new Error( `token --${ name } not found in style.css` );
	return m[ 1 ];
};

const lin = ( c ) => { c /= 255; return c <= 0.04045 ? c / 12.92 : Math.pow( ( c + 0.055 ) / 1.055, 2.4 ); };
const lum = ( hex ) => {
	const n = parseInt( hex.slice( 1 ), 16 );
	return 0.2126 * lin( n >> 16 & 255 ) + 0.7152 * lin( n >> 8 & 255 ) + 0.0722 * lin( n & 255 );
};
const ratio = ( a, b ) => { const x = lum( a ), y = lum( b ); const hi = Math.max( x, y ), lo = Math.min( x, y ); return ( hi + 0.05 ) / ( lo + 0.05 ); };

// [ description, fg token, bg token, minimum ]
const RULES = [
	[ 'body text on paper',        'bl-ink',         'bl-paper', 4.5 ],
	[ 'secondary text on paper',   'bl-ink-mid',     'bl-paper', 4.5 ],
	[ 'accent text on paper',      'bl-accent-text', 'bl-paper', 4.5 ],
	[ 'ink on ice fill (button)',  'bl-ink',         'bl-ice',   4.5 ],
	[ 'paper text on ink',         'bl-paper',       'bl-ink',   4.5 ],
	[ 'pale text on ink',          'bl-pale',        'bl-ink',   4.5 ],
	[ 'ice text on ink',           'bl-ice',         'bl-ink',   4.5 ],
	[ 'steel border on paper',     'bl-steel',       'bl-paper', 3.0 ],
];

let failed = 0;
for ( const [ desc, fg, bg, min ] of RULES ) {
	const r = ratio( token( fg ), token( bg ) );
	const ok = r >= min;
	if ( ! ok ) failed++;
	console.log( `${ ok ? 'ok  ' : 'FAIL' } ${ desc }: ${ r.toFixed( 2 ) } (min ${ min })` );
}

// Guard the rule that is easy to violate by accident.
const iceOnPaper = ratio( token( 'bl-ice' ), token( 'bl-paper' ) );
if ( iceOnPaper >= 3.0 ) {
	console.log( `FAIL --bl-ice is ${ iceOnPaper.toFixed( 2 ) } on paper; it is a FILL token and must stay decorative` );
	failed++;
} else {
	console.log( `ok   --bl-ice correctly unusable as light-bg text (${ iceOnPaper.toFixed( 2 ) })` );
}

process.exit( failed ? 1 : 0 );
```

```php
<?php
/**
 * Season state — decides what the site should emphasise right now.
 *
 * @package blueline
 */

defined( 'ABSPATH' ) || exit;

/**
 * Pure decision function. Kept free of WordPress calls so it can be unit tested.
 *
 * @param array $signals Keys: has_purchasable_product (bool), upcoming_events (int),
 *                       days_to_next_event (int|null), has_playoff_events (bool),
 *                       recent_events (int).
 * @return string One of registration_open|preseason|in_season|playoffs|offseason.
 */
function blueline_decide_season_state( array $signals ): string {
	$has_product = ! empty( $signals['has_purchasable_product'] );
	$upcoming    = (int) ( $signals['upcoming_events'] ?? 0 );
	$days        = $signals['days_to_next_event'] ?? null;
	$playoffs    = ! empty( $signals['has_playoff_events'] );
	$recent      = (int) ( $signals['recent_events'] ?? 0 );

	// Selling a registration is always the loudest signal.
	if ( $has_product ) {
		return 'registration_open';
	}

	if ( $playoffs && $upcoming > 0 ) {
		return 'playoffs';
	}

	if ( $upcoming > 0 ) {
		// Games already played this season means we are mid-season; otherwise it has not started.
		if ( $recent > 0 || ( null !== $days && $days <= 14 ) ) {
			return 'in_season';
		}
		return 'preseason';
	}

	return 'offseason';
}
```

```php
<?php
/**
 * Linking a WordPress user to a SportsPress player.
 *
 * Only ~12% of current-season players carry sp_user, so everything here must
 * behave sensibly when no link exists.
 *
 * @package blueline
 */

defined( 'ABSPATH' ) || exit;

const BLUELINE_PLAYER_USER_META = 'sp_user';
const BLUELINE_MATCH_THRESHOLD  = 0.85;

/**
 * Lowercase, de-accent, strip punctuation, collapse whitespace.
 */
function blueline_normalize_name( string $name ): string {
	$name = trim( $name );
	if ( '' === $name ) {
		return '';
	}
	$translit = @iconv( 'UTF-8', 'ASCII//TRANSLIT', $name );
	if ( false !== $translit ) {
		$name = $translit;
	}
	$name = strtolower( $name );
	$name = str_replace( array( "'", '’' ), '', $name );  // O'Connor -> oconnor
	$name = preg_replace( '/[^a-z0-9]+/', ' ', $name );
	return trim( preg_replace( '/\s+/', ' ', $name ) );
}

/**
 * Token-set similarity, 0.0–1.0. Order-independent so "Lusk Cody" matches "Cody Lusk",
 * and tolerant of extra middle names.
 */
function blueline_name_match_score( string $a, string $b ): float {
	$ta = array_filter( explode( ' ', blueline_normalize_name( $a ) ) );
	$tb = array_filter( explode( ' ', blueline_normalize_name( $b ) ) );
	if ( empty( $ta ) || empty( $tb ) ) {
		return 0.0;
	}
	$sa = array_unique( $ta );
	$sb = array_unique( $tb );
	$common = array_intersect( $sa, $sb );
	// Score against the SMALLER set so extra middle names do not punish a real match.
	$score = count( $common ) / min( count( $sa ), count( $sb ) );
	return round( (float) $score, 4 );
}
```
